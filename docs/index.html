Designed for AI Agents

给 AI 用的邮件收发 CLI
npx u32-ai-email

发邮件、收邮件、多账户，一行命令搞定。JSON 输出、零交互、语义化 exit code —— AI 拿到结果直接解析。

npm: u32-ai-email GitHub llms.txt
零安装，Node ≥ 18SMTP 发件IMAP 只读收件多账户配置30s 超时兜底
agent@work ~
# 1. 添加账户（存 ~/.u32-ai-email/config.json）
$ npx u32-ai-email config add default \
    --host smtp.88.com \
    --user you@88.com --pass 授权码

# 2. 发邮件
$ npx u32-ai-email send --to a@b.com \
    --subject "周报" --html-file report.html \
    --attach report.pdf

# 3. 收邮件（只读，不会动你的邮箱）
$ npx u32-ai-email list --limit 5
$ npx u32-ai-email read --uid 1234

Features

为什么适合 AI

每一处设计都为了让 Agent 少猜、少试、少返工。

为 AI 设计的输出

所有命令输出 JSON、exit code 语义化（0 成功 / 1 用法错 / 2 失败），脚本直接解析，不用猜格式。

发 + 收 全覆盖

SMTP 发件（文本 / HTML / 附件 / 抄送密送），IMAP 收件（list / read / search / fetch），收件全程只读。

多账户

config add work 添加任意账户，--account work 一参切换，默认账户名 default。

零安装即用

零依赖，npx u32-ai-email help 直接用。连接与认证超时各 30 秒，不会挂死任务。

Commands

命令一览

十个子命令，覆盖账户管理与收发全流程。

命令作用
config add / list / remove / default / test账户管理与 SMTP 连接验证pass 打码展示，配置存 ~/.u32-ai-email/config.json
send发邮件--to --subject，正文三选一 --body / --html / --html-file，可选 --attach --cc --bcc --account
list最近邮件uid / 日期 / 发件人 / 主题 / 未读标记
read读单封--uid N，默认纯文本，--raw-html 输出 HTML 正文 + 附件清单
search搜索邮件--from / --subject / --since / --before 至少一项
fetch下载附件--uid N --out 目录
For Agents

AI 集成约定

如果你是 AI Agent，请按这两块执行。

输出约定

  • stdout 输出 JSON，stderr 输出错误 JSON
  • exit code：0 成功 / 1 用法错误 / 2 网络认证发送失败
  • 连接与认证超时各 30 秒
  • 完整说明见 llms.txt

发邮件前的前置检查（必做）

执行任何会收发邮件的任务（尤其长任务）之前，务必先验证邮箱可用：

# 有没有已配置的账户？
$ npx u32-ai-email config list

# SMTP 能连上并通过认证？
$ npx u32-ai-email config test

任一步失败 → 立即停止任务，先让用户完成邮箱配置（config add + 邮箱后台开启 SMTP/IMAP 并获取授权码），避免长任务跑完才发现邮件发不出。
