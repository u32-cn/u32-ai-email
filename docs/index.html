npx u32-ai-email

给 AI 用的邮件收发命令行 —— 发邮件、收邮件、多账户，一行命令搞定

npm: u32-ai-email GitHub: u32-cn/u32-ai-email llms

🤖 为 AI 设计

所有输出 JSON、exit code 语义化、零交互、30s 超时兜底——AI 拿到结果直接解析，不用猜。

📤 发 + 📥 收

SMTP 发件（文本/HTML/附件/抄送密送），IMAP 收件（list / read / search / fetch，全程只读）。

👥 多账户

config add work --host ... 添加任意账户，--account work 一参切换，默认账户名 default。

⚡ 零安装

不需要装任何东西：npx u32-ai-email help 即用。Node ≥ 18。

30 秒上手

# 1. 添加账户（一次即可，存 ~/.u32-ai-email/config.json）
npx u32-ai-email config add default \
  --host smtp.88.com --user you@88.com --pass 授权码 --from-name "AI 助手"

# 2. 发邮件
npx u32-ai-email send --to a@b.com --subject "周报" --html-file report.html --attach report.pdf

# 3. 收邮件（只读，不会动你的邮箱）
npx u32-ai-email list --limit 5
npx u32-ai-email read --uid 1234

命令一览

命令作用
config add/list/remove/default/test账户管理与 SMTP 连接验证
send --to --subject (--body|--html|--html-file)发邮件（可选 --attach/--cc/--bcc/--account）
list [--limit N]最近邮件（uid/日期/发件人/主题/未读）
read --uid N [--raw-html]读单封正文 + 附件清单
search --from|--subject|--since|--before搜索邮件（至少一个条件）
fetch --uid N [--out DIR]下载附件

AI 输出约定

  • stdout 输出 JSON，stderr 输出错误 JSON
  • exit code：0 成功 / 1 用法错误 / 2 网络认证发送失败
  • 连接与认证超时各 30 秒
